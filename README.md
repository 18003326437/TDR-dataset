# TDR-dataset
The dataset of truck-drone routing problem
# Optimizing distributionally robust truck-drone routing problem with ambiguous travelling time by enhanced branch-and-cut algorithm

# Overview
This paper proposes a distributionally robust truck-drone routing (DR-TDR) model
# Dataset
This repository includes the following files used in the experiments:
- Case explanation - Introduces the experimental content.

- Dataset - Contains parameter settings and customer coordinates.

- drone_travel_time_matrix_seconds - Provides the drone travel time matrix.

- truck_travel_time_matrix_seconds - Provides the truck travel time matrix.

- Results report - Reports the relevant experimental results.

- Routings with 40 customers - The optimal routes of the truck and drones are obtained when there are 40 customers.

- Routings with 50 customers - The optimal routes of the truck and drones are obtained when there are 50 customers.

- Algorithm pseudocode - The algorithm pseudocode of the enhanced B&C algorithm.
